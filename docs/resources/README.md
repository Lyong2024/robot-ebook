## 资源质量标准

所有收录的资源都经过以下标准筛选：

1. ✅ **权威性**: 来自官方文档、经典教材、顶级会议论文
2. ✅ **时效性**: 优先选择2020年后的资源
3. ✅ **可访问性**: 提供可访问的链接
4. ✅ **实用性**: 对学习有实际帮助

## 使用建议

1. **初学者**: 建议从[按章节索引](./by-chapter.md)开始，跟随电子书章节顺序学习
2. **有经验者**: 可以通过[按主题索引](./by-topic.md)快速找到感兴趣的领域
3. **研究者**: 推荐查看[按类型索引](./by-type.md)中的论文和数据集部分

## 贡献指南

如果你发现了优质的学习资源，欢迎通过以下方式贡献：

1. 确保资源符合质量标准
2. 按照[资源模板](../.vitepress/resource-template.md)格式整理
3. 提交到相应的索引文件
