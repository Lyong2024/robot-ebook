# 拓展资源模板

本文档定义了电子书中拓展资源的统一格式和样式规范。

## 资源类型分类

### 📚 经典书籍
- **标题**: 书名（中英文）
- **作者**: 作者姓名
- **出版年份**: YYYY年
- **语言**: 中文/英文
- **适合人群**: 初学者/中级/高级
- **核心价值**: 为什么推荐这本书
- **推荐章节**: 具体章节列表
- **在线资源**: 免费版链接（如有）

### 📝 学术论文
- **标题**: 论文标题（英文）
- **作者**: 作者列表
- **发表**: 会议/期刊名称，年份
- **核心价值**: 论文的主要贡献
- **论文链接**: DOI或arXiv链接
- **开源代码**: GitHub链接（如有）

### 🎓 在线课程
- **课程名**: 课程标题
- **机构/讲师**: 大学或讲师名称
- **平台**: Coursera/edX/Udemy等
- **时长**: 约XX小时
- **费用**: 免费/付费
- **语言**: 中文/英文
- **核心内容**: 课程大纲
- **为什么推荐**: 推荐理由

### 🎬 视频教程
- **标题**: 视频/频道名称
- **平台**: YouTube/B站等
- **链接**: 视频链接
- **时长**: 约XX小时
- **语言**: 中文/英文
- **观看量**: 数据（如有）
- **核心内容**: 内容简介
- **为什么推荐**: 推荐理由

### 🚀 开源项目
- **项目名**: 项目名称
- **链接**: GitHub链接
- **开发者**: 个人/组织
- **Star数**: GitHub星标数
- **核心功能**: 主要功能列表
- **文档**: 文档链接
- **为什么推荐**: 推荐理由

### 📊 数据集
- **名称**: 数据集名称
- **链接**: 下载链接
- **类型**: 数据类型
- **规模**: 数据规模
- **为什么推荐**: 推荐理由

### 🛠️ 工具和库
- **名称**: 工具名称
- **链接**: 官网或GitHub
- **核心功能**: 主要功能
- **安装**: 安装命令
- **为什么推荐**: 推荐理由

### 🏢 研究机构和实验室
- **名称**: 机构名称
- **链接**: 官网链接
- **研究方向**: 主要研究领域
- **代表成果**: 重要论文或项目

### 🎤 顶级会议和期刊
- **名称**: 会议/期刊名称
- **类型**: 会议/期刊
- **领域**: 研究领域
- **链接**: 官网链接

### 🌏 中文资源
- **名称**: 资源名称
- **类型**: 博客/公众号/知乎/B站等
- **链接**: 访问链接
- **核心内容**: 内容简介

## 样式规范

1. **标题层级**: 使用##、###、####
2. **加粗**: 使用**文本**表示关键字段
3. **列表**: 使用-或数字列表
4. **代码**: 使用`代码`或```代码块```
5. **链接**: 使用[文本](URL)格式
6. **引用**: 使用>引用文本

## 质量标准

1. **权威性**: 优先选择官方文档、经典教材、顶级会议论文
2. **时效性**: 优先选择2020年后的资源
3. **可访问性**: 提供可访问的链接
4. **平衡性**: 中英文资源平衡
5. **完整性**: 每种资源类型都应包含
6. **实用性**: 提供具体的学习路径和建议

## 资源索引

所有拓展资源应在以下位置建立索引：
- 按章节索引：docs/resources/by-chapter.md
- 按类型索引：docs/resources/by-type.md
- 按主题索引：docs/resources/by-topic.md

## 更新维护

- 定期检查链接有效性
- 更新资源的Star数、观看量等数据
- 添加新的优质资源
- 移除失效或过时的资源
