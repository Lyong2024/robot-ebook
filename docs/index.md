## 为什么选择这本书？

这不是一本传统的教科书。我们采用**"先感性认识、再理性推导、后实践应用"**的三层学习法，让你：

- ✅ 用 Arduino 控制电机和传感器
- ✅ 用 ROS 2 构建机器人软件系统
- ✅ 用 OpenCV 和 YOLO 让机器人"看懂"世界
- ✅ 用 SLAM 和导航算法让机器人自主移动
- ✅ 用 MoveIt 2 控制机械臂精确抓取物体
- ✅ 尝试最前沿的具身智能模型

## 学习路径

```
[零基础] → [基础 1-2章] → [硬件 3-6章] → [软件栈 7-9章]
    ↓
[传感器、导航与视觉 10-12章] → [机械臂、交互与项目 13-15章]
    ↓
[前沿 16-17章] → [综合项目 18章]
    ↓
[综合项目 18章] → [你的第一个机器人！]
```

## 适合谁？

- 🎓 **完全零基础的学习者**：想要进入机器人领域但不知从何开始
- 💼 **有编程基础的开发者**：想要转型到机器人开发领域
- 🔬 **学生和研究者**：需要系统学习机器人技术栈
- 🏭 **工程师和创客**：想要动手制作自己的机器人项目

## 时间投入

- **每章学习时间**：2-4 小时（阅读 + 理解）
- **每章练习时间**：2-6 小时（动手实践）
- **综合项目时间**：20-40 小时（分阶段完成）
- **总计**：150-300 小时（根据你的基础和投入程度）
