### 第18章：制作你自己的桌面机器人
**核心知识点：** 将所学知识融会贯通
- 18.1 项目概述
  - 目标：制作一个可以巡线、避障并抓取小物的桌面机器人
  - 技能覆盖：硬件、软件、仿真、视觉、控制
- 18.2 硬件清单
  - 底盘：差速驱动（Differential Drive）
  - 传感器：摄像头、超声波、红外
  - 执行器：直流电机、伺服电机（机械爪）
  - 控制器：ESP32 或 Raspberry Pi
  - 电源：锂电池 + 稳压模块
  - 购买链接与预算（约 $100-200）
- 18.3 阶段 1：底盘组装与基本运动
  - 组装步骤（配图占位符）
  - Arduino 代码：控制电机前进、后退、转向
  - 测试与调试
- 18.4 阶段 2：巡线功能
  - 红外传感器阵列
  - PID 控制算法
  - 代码实现与调优
- 18.5 阶段 3：避障功能
  - 超声波传感器
  - 简单的避障逻辑
  - 与巡线的融合
- 18.6 阶段 4：视觉识别
  - 摄像头安装
  - 使用 OpenCV 或 YOLO 检测目标物体
  - 与 ROS 2 的集成（可选）
- 18.7 阶段 5：机械爪抓取
  - 伺服电机控制
  - 抓取策略
  - 完整的任务流程：寻找 → 接近 → 抓取
- 18.8 故障排除指南
  - 常见问题与解决方案
- 18.9 扩展方向
  - 添加语音控制
  - 远程操控（WiFi）
  - 更复杂的 AI 决策
- **推荐开源项目：** 
  - TurtleBot3 (https://github.com/ROBOTIS-GIT/turtlebot3)
  - ROSbot (https://github.com/husarion/rosbot_description)
- **学习目标复查**
- **问答环节**（5题）
- **动手练习**（3题，含完整项目实现）
