### 第18章：制作你自己的桌面机器人
**核心知识点：** 将所学知识融会贯通
- 18.1 项目概述
  - 目标：制作一个可以巡线、避障并抓取小物的桌面机器人
  - 技能覆盖：硬件、软件、仿真、视觉、控制
- 18.2 硬件清单
  - 底盘：差速驱动（Differential Drive）
  - 传感器：摄像头、超声波、红外
  - 执行器：直流电机、伺服电机（机械爪）
  - 控制器：ESP32 或 Raspberry Pi
  - 电源：锂电池 + 稳压模块
  - 购买链接与预算（约 $100-200）
- 18.3 阶段 1：底盘组装与基本运动
  - 组装步骤（配图占位符）
  - Arduino 代码：控制电机前进、后退、转向
  - 测试与调试
- 18.4 阶段 2：巡线功能
  - 红外传感器阵列
  - PID 控制算法
  - 代码实现与调优
- 18.5 阶段 3：避障功能
  - 超声波传感器
  - 简单的避障逻辑
  - 与巡线的融合
- 18.6 阶段 4：视觉识别
  - 摄像头安装
  - 使用 OpenCV 或 YOLO 检测目标物体
  - 与 ROS 2 的集成（可选）
- 18.7 阶段 5：机械爪抓取
  - 伺服电机控制
  - 抓取策略
  - 完整的任务流程：寻找 → 接近 → 抓取
- 18.8 故障排除指南
  - 常见问题与解决方案
- 18.9 扩展方向
  - 添加语音控制
  - 远程操控（WiFi）
  - 更复杂的 AI 决策
- **推荐开源项目：** 
  - TurtleBot3 (https://github.com/ROBOTIS-GIT/turtlebot3)
  - ROSbot (https://github.com/husarion/rosbot_description)

## 💡 学习路径建议

### 入门路径（第1个月）
1. 观看**野生技术协会**的Arduino小车教程，了解基本概念
2. 购买Arduino入门套件（约$30-50），完成基础实验
3. 在**Tinkercad Circuits**上设计和仿真简单电路
4. 完成本章的阶段1：底盘组装与基本运动

### 进阶路径（第2-3个月）
1. 学习**Adafruit Learning System**的传感器教程
2. 完成本章的阶段2-3：巡线和避障功能
3. 研究**Arduino Robot Car**开源项目，学习代码结构
4. 加入Arduino Forum，参与社区讨论

### 高级路径（第4-6个月）
1. 学习OpenCV基础，完成本章的阶段4：视觉识别
2. 研究**TurtleBot3**项目，学习ROS 2集成
3. 完成本章的阶段5：机械爪抓取
4. 参加**RoboCup Junior**或**中国机器人大赛**，检验学习成果

### 专家路径（6个月以上）
1. 深入学习《The Art of Electronics》，理解电路设计原理
2. 学习《Control Systems Engineering》，掌握高级控制算法
3. 开发自己的创新项目，在**Hackaday**或**Instructables**分享
4. 为开源机器人项目贡献代码
