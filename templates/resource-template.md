# 拓展资源模板

本模板用于为电子书章节添加拓展资源。每个资源应包含完整的元数据和描述。

## 资源类型分类

### 📚 学术论文 (Paper)
用于引用学术期刊、会议论文、技术报告等权威学术文献。

**模板格式：**
```markdown
::: resource-card paper
**标题**: [论文标题]  
**作者**: 作者1, 作者2, 等  
**发表**: 期刊/会议名称, 年份  
**DOI/链接**: [访问链接]  
**核心观点**: 一句话概括论文的主要贡献或发现  
**推荐理由**: 为什么这篇论文对理解该知识点重要  
**难度**: ⭐⭐⭐ (1-5星，5星最难)
:::
```

### 📖 书籍 (Book)
用于引用教材、专著、技术书籍等。

**模板格式：**
```markdown
::: resource-card book
**书名**: [书籍名称]  
**作者**: 作者姓名  
**出版社**: 出版社名称  
**出版年份**: YYYY  
**ISBN**: ISBN号码  
**相关章节**: 第X章/第Y-Z页  
**内容简介**: 简要介绍书籍内容和相关章节  
**推荐理由**: 为什么推荐这本书  
**难度**: ⭐⭐⭐
:::
```

## 使用示例

### 示例1：为"机器人定义"添加ISO标准

```markdown
## 拓展阅读

::: resource-card standard
**标准号**: ISO 8373:2021  
**标题**: Robots and robotic devices — Vocabulary  
**发布机构**: International Organization for Standardization (ISO)  
**发布年份**: 2021  
**链接**: https://www.iso.org/standard/75539.html  
**适用范围**: 定义机器人和机器人设备的术语和分类  
**核心内容**: 提供了机器人的官方定义，包括工业机器人、服务机器人等分类标准，是全球机器人行业的权威参考
:::
```

```markdown
**ISBN**: 978-0133489798  
**相关章节**: 第2-4章 (正运动学、逆运动学、雅可比矩阵)

**推荐理由**: 被全球数百所大学采用为教材，理论严谨且实用性强，适合系统学习机器人运动学
```


## 组织结构建议

在每个章节末尾添加"拓展阅读"部分，按资源类型分组：

```markdown
## 拓展阅读

### 📚 权威文献

[论文和书籍资源]

### 🎥 视频教程

[视频资源]

### 🛠️ 实践工具

[工具和项目资源]

### 📝 深度文章

[博客和文章资源]
```

## 引用格式规范

当在正文中引用拓展资源时，使用以下格式：

```markdown
根据ISO 8373:2021标准的定义[^1]，机器人是...

[^1]: ISO 8373:2021 - Robots and robotic devices — Vocabulary
```

## 质量标准

1. **权威性**: 优先选择学术论文、官方文档、知名专家的内容
2. **时效性**: 优先选择2020年后的资源，除非是经典文献
3. **可访问性**: 确保链接有效，优先选择免费或开放获取的资源
4. **相关性**: 资源内容必须与章节知识点直接相关
5. **多样性**: 平衡中英文资源，照顾不同语言背景的读者
6. **难度梯度**: 为同一知识点提供不同难度的资源，从入门到高级

## 维护说明

- 每季度检查一次外部链接的有效性
- 及时更新过时的资源
- 根据读者反馈调整推荐资源
- 保持资源列表的精简，每个知识点不超过5个核心资源
