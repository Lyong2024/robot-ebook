# 第5章：电机与驱动：让机器人动起来

如果说微控制器是机器人的"大脑"，那么电机就是机器人的"肌肉"。无论是扫地机器人在地板上穿梭，还是机械臂精准抓取物体，又或是无人机在空中盘旋，背后都离不开电机的驱动。

但电机不是简单地"通电就转"。不同类型的电机有不同的特性，需要不同的驱动方式。更重要的是，微控制器的引脚输出电流很小（通常只有几十毫安），根本无法直接驱动电机——这就需要**电机驱动电路**作为"中介"。

本章将带你理解电机的分类、驱动原理，以及如何用 Arduino 控制各种电机。

---

## 5.1 电机的分类（直流/步进/伺服/无刷）

电机家族庞大，但在机器人领域，最常用的是以下四种：

### 直流电机（DC Motor）

**工作原理**：通电后持续旋转，改变电压极性可以改变旋转方向。

**特点**：
- **结构简单**：只有两根线，接上电源就能转
- **速度快**：转速可达数千到数万转/分钟
- **无位置反馈**：不知道转了多少圈，也不知道当前角度
- **价格便宜**：几元到几十元

**类比**：就像电风扇——通电就转，但你不知道扇叶转了多少圈。

**应用场景**：
- 小车的轮子驱动
- 风扇、水泵
- 玩具车

**真实案例**：  
你想做一个两轮平衡车。两个直流电机分别驱动左右轮，通过调节两侧电机的速度差来实现转向。但因为没有位置反馈，你需要额外加装**编码器**（Encoder）来测量轮子转了多少圈。

---

### 步进电机（Stepper Motor）

**工作原理**：通过脉冲信号控制，每个脉冲让电机转动一个固定角度（通常是 1.8° 或 0.9°）。

**特点**：
- **精确定位**：可以精确控制转动角度（比如"转 90°"）
- **开环控制**：不需要位置反馈，发送多少脉冲就转多少步
- **低速扭矩大**：在低速时能输出很大的力矩
- **高速性能差**：转速超过一定值后容易"失步"（跟不上脉冲）
- **价格适中**：几十到几百元

**类比**：就像钟表的秒针——每秒跳动一格，精确可控。

**应用场景**：
- 3D 打印机（控制打印头的 X、Y、Z 轴移动）
- CNC 雕刻机
- 相机云台

**真实案例**：  
你想做一个绘图机器人。步进电机控制笔的 X 轴和 Y 轴移动。你发送指令"X 轴移动 100 步，Y 轴移动 50 步"，电机就会精确执行，画出一条直线。

---

### 伺服电机（Servo Motor）

**工作原理**：内置位置反馈系统（电位器或编码器），可以精确控制转动角度。

**特点**：
- **角度控制**：可以精确转到指定角度（比如 0°、90°、180°）
- **闭环控制**：内置反馈系统，自动修正误差
- **扭矩适中**：在整个角度范围内保持稳定扭矩
- **角度有限**：普通伺服只能转 180° 或 270°（也有 360° 连续旋转型）
- **价格适中**：几元到几百元

**类比**：就像你伸手去拿杯子——大脑发出指令"手臂弯曲 90°"，肌肉和神经系统会自动调整，直到达到目标角度。

**应用场景**：
- 机械臂的关节
- 遥控飞机的舵面控制
- 机器人的头部转动

**真实案例**：  
你想做一个四足机器人。每条腿有 3 个关节，每个关节用一个伺服电机控制。你发送指令"前腿抬起 45°"，伺服电机会自动转到 45° 并保持。

---

### 无刷电机（Brushless Motor, BLDC）

**工作原理**：通过电子换向（而不是机械电刷）驱动，效率更高、寿命更长。

**特点**：
- **效率高**：能量转换效率可达 90% 以上
- **寿命长**：没有电刷磨损，可以持续运行数万小时
- **功率密度高**：体积小但输出功率大
- **需要专用驱动器**：控制复杂，需要电调（ESC）
- **价格较高**：几十到数千元

**类比**：就像电动汽车的电机——高效、强劲、耐用。

**应用场景**：
- 无人机的螺旋桨
- 电动滑板车
- 高性能机器人

**真实案例**：  
你想做一个四旋翼无人机。四个无刷电机分别驱动四个螺旋桨。通过调节四个电机的转速差，可以实现前进、后退、左转、右转、上升、下降等动作。

---

### 四种电机的对比

| 特性 | 直流电机 | 步进电机 | 伺服电机 | 无刷电机 |
|------|---------|---------|---------|---------|
| **位置控制** | 无（需外接编码器） | 精确（开环） | 精确（闭环） | 无（需外接传感器） |
| **速度控制** | 容易 | 较难（高速易失步） | 适中 | 容易 |
| **扭矩** | 适中 | 低速大，高速小 | 稳定 | 大 |
| **效率** | 70-80% | 60-70% | 70-80% | 90%+ |
| **价格** | 低 | 中 | 中 | 高 |
| **控制复杂度** | 简单 | 中等 | 简单 | 复杂 |

## 5.2 电机驱动电路（H桥、L298N、TB6612）

### 为什么不能直接用 Arduino 驱动电机？

Arduino 的数字引脚输出电流通常只有 **20-40mA**，而一个小型直流电机的工作电流可能是 **200-500mA**，大型电机甚至需要 **数安培**。如果直接连接，会烧毁 Arduino。

**类比**：就像你用一根吸管去吹动一个风车——气流太小，根本吹不动。

解决方案：使用**电机驱动电路**作为"功率放大器"。Arduino 发出控制信号（小电流），驱动电路输出大电流驱动电机。

---

### H 桥电路：电机驱动的核心

**H 桥**（H-Bridge）是最常用的电机驱动电路，因为电路形状像字母"H"而得名。

#### 工作原理

H 桥由 4 个开关（通常是 MOSFET 或三极管）组成：

```
        +V
         |
    S1 --+-- S2
         |
    Motor
         |
    S3 --+-- S4
         |
        GND
```

通过控制 4 个开关的通断，可以实现：
1. **正转**：S1 和 S4 闭合，S2 和 S3 断开 → 电流从左到右流过电机
2. **反转**：S2 和 S3 闭合，S1 和 S4 断开 → 电流从右到左流过电机
3. **刹车**：S1 和 S2 闭合（或 S3 和 S4 闭合）→ 电机两端短路，快速停止
4. **滑行**：所有开关断开 → 电机自由滑行

**注意**：绝对不能让 S1 和 S3 同时闭合（或 S2 和 S4 同时闭合），否则会造成电源短路！

---

### L298N：经典的双路 H 桥驱动模块

**特点**：
- 可以同时驱动 **2 个直流电机** 或 **1 个步进电机**
- 每路最大电流 **2A**
- 工作电压 **5-35V**
- 内置续流二极管（保护电路）
- 价格便宜（10-20 元）

**缺点**：
- 效率较低（约 70%），发热严重
- 体积较大

**引脚说明**：
- **ENA, ENB**：使能引脚（控制电机是否工作）
- **IN1, IN2**：控制电机 A 的方向
- **IN3, IN4**：控制电机 B 的方向
- **OUT1, OUT2**：电机 A 的输出
- **OUT3, OUT4**：电机 B 的输出

**控制逻辑**（以电机 A 为例）：

| IN1 | IN2 | 电机状态 |
|-----|-----|---------|
| LOW | LOW | 停止 |
| HIGH | LOW | 正转 |
| LOW | HIGH | 反转 |
| HIGH | HIGH | 刹车 |

---

### TB6612：更高效的替代方案

**特点**：
- 可以驱动 **2 个直流电机**
- 每路最大电流 **1.2A**（峰值 3.2A）
- 工作电压 **2.7-5.5V**（电机电压）、**2.7-5.5V**（逻辑电压）
- 效率高（约 95%），几乎不发热
- 体积小

**优势**：
- 比 L298N 效率高、发热少
- 支持 PWM 调速
- 有独立的逻辑电压输入（可以用 3.3V 控制）

**引脚说明**：
- **PWMA, PWMB**：PWM 调速引脚
- **AIN1, AIN2**：控制电机 A 的方向
- **BIN1, BIN2**：控制电机 B 的方向
- **STBY**：待机引脚（LOW 时所有输出关闭）

---

## 5.3 PWM 控制电机速度

### 什么是 PWM？

**PWM**（Pulse Width Modulation，脉宽调制）是一种通过改变脉冲宽度来控制平均电压的技术。

**类比**：就像你快速地开关电灯——如果开的时间长、关的时间短，灯看起来就亮；如果开的时间短、关的时间长，灯看起来就暗。

#### PWM 的关键参数

1. **频率**（Frequency）：每秒钟脉冲的次数（单位：Hz）
   - Arduino 的 PWM 频率通常是 490Hz 或 980Hz
   
2. **占空比**（Duty Cycle）：高电平占整个周期的百分比
   - 0% = 完全关闭
   - 50% = 一半时间开、一半时间关
   - 100% = 完全开启

**示例**：
```
占空比 25%:  ▁▁▁█▁▁▁█▁▁▁█
占空比 50%:  ▁▁██▁▁██▁▁██
占空比 75%:  ▁███▁███▁███
```

### 用 PWM 控制电机速度

```cpp
// 使用 L298N 驱动一个直流电机

const int ENA = 9;   // 使能引脚（PWM）
const int IN1 = 7;   // 方向控制 1
const int IN2 = 8;   // 方向控制 2

void setup() {
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
}

void loop() {
  // 正转，速度 50%
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, 128);  // 0-255，128 约等于 50%
  delay(2000);
  
  // 正转，速度 100%
  analogWrite(ENA, 255);
  delay(2000);
  
  // 停止
  analogWrite(ENA, 0);
  delay(1000);
  
  // 反转，速度 75%
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  analogWrite(ENA, 192);  // 192/255 ≈ 75%
  delay(2000);
  
  // 停止
  analogWrite(ENA, 0);
  delay(1000);
}
```

**代码解析**：
- `analogWrite(ENA, value)`：输出 PWM 信号，value 范围 0-255
  - 0 = 0% 占空比 = 电机停止
  - 128 = 50% 占空比 = 电机半速
  - 255 = 100% 占空比 = 电机全速

## 5.4 伺服电机的控制

### 伺服电机的控制信号

伺服电机通过 **PWM 信号** 控制角度，但这里的 PWM 不是控制速度，而是控制位置。

**标准伺服信号**：
- **频率**：50Hz（每 20ms 一个脉冲）
- **脉宽**：1-2ms
  - 1.0ms → 0°
  - 1.5ms → 90°
  - 2.0ms → 180°

**类比**：就像你告诉服务员"给我倒半杯水"——你不是控制倒水的速度，而是控制最终的水位。

### 使用 Servo 库控制伺服

```cpp
#include <Servo.h>

Servo myServo;  // 创建伺服对象

void setup() {
  myServo.attach(9);  // 伺服信号线连接到引脚 9
}

void loop() {
  // 转到 0°
  myServo.write(0);
  delay(1000);
  
  // 转到 90°
  myServo.write(90);
  delay(1000);
  
  // 转到 180°
  myServo.write(180);
  delay(1000);
  
  // 平滑扫描（0° → 180°）
  for (int angle = 0; angle <= 180; angle++) {
    myServo.write(angle);
    delay(15);  // 每 15ms 移动 1°
  }
  
  // 平滑扫描（180° → 0°）
  for (int angle = 180; angle >= 0; angle--) {
    myServo.write(angle);
    delay(15);
  }
}
```

**关键函数**：
- `myServo.attach(pin)`：将伺服连接到指定引脚
- `myServo.write(angle)`：设置目标角度（0-180）
- `myServo.read()`：读取当前角度
- `myServo.detach()`：断开伺服（停止发送信号）

## 5.5 步进电机的控制

### 步进电机的工作模式

步进电机有 4 根或 6 根线，需要按特定顺序给线圈通电才能转动。

#### 单相激励（Wave Drive）

每次只有一个线圈通电，功耗最低但扭矩最小。

#### 双相激励（Full Step）

每次有两个线圈通电，扭矩大但功耗高。

#### 半步模式（Half Step）

单相和双相交替，步进角度减半，运动更平滑。

### 使用 Stepper 库控制步进电机

```cpp
#include <Stepper.h>

// 定义步进电机的步数（每圈）
const int stepsPerRevolution = 200;  // 1.8° 步进角 = 360/1.8 = 200 步

// 创建步进电机对象，连接到引脚 8, 9, 10, 11
Stepper myStepper(stepsPerRevolution, 8, 9, 10, 11);

void setup() {
  // 设置转速（RPM）
  myStepper.setSpeed(60);  // 60 转/分钟
}

void loop() {
  // 顺时针转一圈
  myStepper.step(stepsPerRevolution);
  delay(1000);
  
  // 逆时针转一圈
  myStepper.step(-stepsPerRevolution);
  delay(1000);
  
  // 转 90°（1/4 圈）
  myStepper.step(stepsPerRevolution / 4);
  delay(1000);
}
```

**关键函数**：
- `Stepper(steps, pin1, pin2, pin3, pin4)`：创建步进电机对象
- `setSpeed(rpm)`：设置转速（转/分钟）
- `step(steps)`：转动指定步数（正数顺时针，负数逆时针）

## 5.6 实践：用 Arduino 控制直流电机和伺服电机

### 项目 1：遥控小车

**硬件**：
- Arduino Uno
- L298N 驱动模块
- 2 个直流电机
- 电池（7.4V 或 12V）

**功能**：通过串口发送指令控制小车前进、后退、左转、右转。

**代码**：

```cpp
// 遥控小车控制程序

// 左电机
const int ENA = 9;
const int IN1 = 7;
const int IN2 = 8;

// 右电机
const int ENB = 10;
const int IN3 = 5;
const int IN4 = 6;

void setup() {
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENB, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  
  Serial.begin(9600);
  Serial.println("遥控小车已启动");
  Serial.println("指令: F=前进, B=后退, L=左转, R=右转, S=停止");
}

void loop() {
  if (Serial.available() > 0) {
    char command = Serial.read();
    
    switch (command) {
      case 'F':  // 前进
        forward(200);
        Serial.println("前进");
        break;
        
      case 'B':  // 后退
        backward(200);
        Serial.println("后退");
        break;
        
      case 'L':  // 左转
        turnLeft(150);
        Serial.println("左转");
        break;
        
      case 'R':  // 右转
        turnRight(150);
        Serial.println("右转");
        break;
        
      case 'S':  // 停止
        stop();
        Serial.println("停止");
        break;
    }
  }
}

// 前进
void forward(int speed) {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
}

// 后退
void backward(int speed) {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
}

// 左转（左轮停止，右轮前进）
void turnLeft(int speed) {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, 0);
  analogWrite(ENB, speed);
}

// 右转（右轮停止，左轮前进）
void turnRight(int speed) {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, speed);
  analogWrite(ENB, 0);
}

// 停止
void stop() {
  analogWrite(ENA, 0);
  analogWrite(ENB, 0);
}
```

### 项目 2：机械臂抓取

**硬件**：
- Arduino Uno
- 3 个伺服电机（底座旋转、手臂抬升、爪子开合）
- 电源（5V 2A）

**功能**：控制机械臂抓取物体。

**代码**：

```cpp
#include <Servo.h>

// 创建 3 个伺服对象
Servo baseServo;   // 底座旋转
Servo armServo;    // 手臂抬升
Servo gripperServo; // 爪子开合

void setup() {
  baseServo.attach(9);
  armServo.attach(10);
  gripperServo.attach(11);
  
  Serial.begin(9600);
  Serial.println("机械臂已启动");
  
  // 初始位置
  baseServo.write(90);
  armServo.write(90);
  gripperServo.write(90);
  delay(1000);
}

void loop() {
  // 演示抓取动作
  Serial.println("开始抓取...");
  
  // 1. 打开爪子
  gripperServo.write(180);
  delay(500);
  
  // 2. 手臂下降
  armServo.write(45);
  delay(1000);
  
  // 3. 关闭爪子（抓取）
  gripperServo.write(90);
  delay(500);
  
  // 4. 手臂抬升
  armServo.write(135);
  delay(1000);
  
  // 5. 底座旋转 90°
  baseServo.write(180);
  delay(1000);
  
  // 6. 手臂下降
  armServo.write(45);
  delay(1000);
  
  // 7. 打开爪子（释放）
  gripperServo.write(180);
  delay(500);
  
  // 8. 返回初始位置
  armServo.write(90);
  delay(500);
  baseServo.write(90);
  delay(1000);
  
  Serial.println("抓取完成");
  delay(2000);
}
```

**扩展功能**：
- 通过串口发送指令控制每个关节的角度
- 添加按钮手动控制
- 记录和回放动作序列

2. **丰富的库支持**：提供易用的 Arduino 库
3. **高性能**：使用 TB6612 驱动芯片，效率高、发热少
4. **可堆叠**：最多可以堆叠 32 块，控制 128 个电机

**示例代码**：

```cpp
#include <Adafruit_MotorShield.h>

// 创建 Motor Shield 对象
Adafruit_MotorShield AFMS = Adafruit_MotorShield();

// 创建电机对象（连接到 M1 端口）
Adafruit_DCMotor *motor = AFMS.getMotor(1);

void setup() {
  AFMS.begin();  // 初始化 Motor Shield
  motor->setSpeed(150);  // 设置速度（0-255）
}

void loop() {
  motor->run(FORWARD);   // 正转
  delay(2000);
  
  motor->run(BACKWARD);  // 反转
  delay(2000);
  
  motor->run(RELEASE);   // 停止
  delay(1000);
}
```

## 问答环节

### Q1: 为什么不能直接用 Arduino 的数字引脚驱动直流电机？如果强行连接会发生什么？

**答**：Arduino 的数字引脚存在三个关键限制，使其无法直接驱动电机。首先是电流限制：每个 I/O 引脚最大只能提供约 40mA 电流，而即使是小型直流电机（如 TT 马达）的工作电流也在 100-300mA，堵转电流更可达 1A 以上。其次是电压限制：Arduino 引脚输出电压为 5V 或 3.3V，而许多电机需要 6V、12V 甚至更高电压才能获得足够扭矩。最后是方向控制问题：单个引脚只能提供单向电流，无法实现电机的正反转。

如果强行将电机直接连接到 Arduino 引脚，最可能的后果是烧毁该引脚甚至整个微控制器芯片。电机启动瞬间的浪涌电流会超过引脚的安全阈值，导致内部晶体管过热损坏。即使侥幸没有立即损坏，长期过载也会导致引脚性能下降或间歇性故障。此外，电机作为感性负载，在断电瞬间会产生反向电动势（back-EMF），这个电压尖峰可能达到数十伏，足以击穿微控制器的保护二极管。

正确的做法是使用电机驱动模块作为"功率放大器"。Arduino 引脚只需提供低功率的控制信号（几毫安），驱动模块通过 H 桥电路从外部电源获取大电流来驱动电机。这种设计遵循了"信号与功率分离"的原则，既保护了微控制器,又能为电机提供充足的功率。同时，优质的驱动模块还集成了续流二极管、过流保护等电路，进一步提升系统可靠性。

### Q2: H 桥电路有四个开关（S1-S4），如果同时闭合 S1 和 S2（或 S3 和 S4）会发生什么？驱动芯片如何防止这种情况？

**答**：如果同时闭合同一侧的上下两个开关（如 S1 和 S2），会形成从电源正极到负极的直通路径，这就是危险的"shoot-through"（直通）现象。此时电流不经过电机负载，而是直接从 VCC 流向 GND，由于导线和开关的电阻极小（通常小于 0.1Ω），根据欧姆定律，电流会瞬间飙升到数十甚至上百安培。这个短路电流会在毫秒级时间内烧毁 MOSFET 或三极管开关，同时可能损坏电源、熔断保险丝，甚至引发电池起火。

专业的电机驱动芯片通过多重机制防止直通。最基本的是"互锁逻辑"（interlock logic）：芯片内部的逻辑电路确保同一桥臂的上下开关永远不会同时导通，当一个开关打开时，另一个必须关闭。更进一步的是"死区时间"（dead time）设计：在切换开关状态时，芯片会插入几百纳秒到几微秒的延迟，确保一个开关完全关断后，另一个才开始导通。例如 TB6612 芯片的死区时间约为 1μs，这个短暂的"空白期"虽然会略微降低效率，但能有效避免开关特性差异导致的瞬时重叠。

L298N 和 TB6612 等芯片还提供了使能引脚（ENA/ENB 或 STBY）作为"总开关"。当检测到异常输入组合或过热时，芯片可以立即切断所有输出，进入安全模式。此外，输入端的施密特触发器可以过滤信号毛刺，防止干扰导致的误触发。作为开发者，我们也应该在代码层面避免同时输出冲突的控制信号，例如在改变电机方向前先停止 PWM 输出，或使用状态机确保指令的原子性。

### Q3: 用 PWM 控制电机速度时，为什么频率不能太低也不能太高？如何为你的项目选择合适的 PWM 频率？

**答**：PWM 频率过低会导致电机运转不平滑。例如使用 50Hz（Arduino 默认的 490Hz 已经足够，但假设降到 50Hz）时，电机会在"通电-断电"之间产生明显的脉动，表现为抖动、噪音增大和扭矩波动。这是因为电机的机械惯性无法跟上电信号的快速变化，转子会在每个 PWM 周期内经历加速-减速过程。对于精密应用（如相机云台、绘图仪），这种速度波动会直接影响控制精度。更严重的是，低频 PWM 可能与电机的机械谐振频率重合，引发共振放大效应，加剧振动甚至损坏机械结构。

PWM 频率过高则会增加开关损耗和电磁干扰。MOSFET 或三极管在开关瞬间会同时承受高电压和高电流，产生显著的功率损耗（开关损耗与频率成正比）。例如将频率从 1kHz 提升到 20kHz，驱动芯片的发热可能增加数倍，需要更大的散热片。同时，高频开关会产生丰富的高次谐波，通过电源线和空间辐射出去，干扰无线通信（如蓝牙、WiFi）和模拟传感器。此外，过高频率会使驱动芯片的死区时间占比增大，实际有效占空比降低，影响电机的最大输出功率。

选择 PWM 频率需要平衡多个因素。对于普通直流电机，1-20kHz 是理想范围：Arduino 默认的 490Hz（引脚 5、6 为 980Hz）适合大多数场景；如果追求更安静的运行，可以提升到 20kHz 以上进入超声波频段（人耳听不到）。对于步进电机，频率取决于步进速度，通常在 100Hz-2kHz。伺服电机则使用固定的 50Hz PWM（周期 20ms）。实践中可以通过示波器观察电机电流波形：如果看到明显的锯齿波，说明频率偏低；如果驱动芯片过热或出现通信干扰，则需要降低频率。还要查阅驱动芯片数据手册，确保工作在推荐的频率范围内。

### Q4: 伺服电机的 PWM 控制信号（50Hz，脉宽 1-2ms）与直流电机的 PWM 调速信号（490Hz，占空比 0-100%）有什么本质区别？

**答**：这两种 PWM 信号虽然都是脉冲宽度调制，但编码的信息和作用机制完全不同。伺服电机的 PWM 是"位置编码信号"：固定的 50Hz 频率（20ms 周期）中，高电平脉宽的绝对时长（1ms、1.5ms、2ms）代表目标角度（0°、90°、180°）。伺服电机内部有控制电路、电位计和反馈系统，它会持续读取 PWM 信号，将当前角度与目标角度比较，驱动电机转动直到两者一致后停止。这是一个闭环控制系统，PWM 信号是"命令"而非"动力"。

直流电机的 PWM 则是"功率调制信号"：通过改变占空比（高电平时间占总周期的比例）来调节电机两端的平均电压，从而控制转速。例如 50% 占空比相当于将 12V 电源"削减"为 6V 平均电压。这是开环控制，电机没有反馈机制，转速会受负载影响——同样的 PWM 占空比，空载时转得快，带负载时转得慢。频率选择更灵活（通常 490Hz-20kHz），只要足够高以平滑电流波形即可。

从硬件角度看，伺服电机的信号线只需传递微弱的控制信号（几毫安），真正的驱动电流由伺服内部电路从电源线获取，因此可以直接连接 Arduino 引脚。而直流电机的 PWM 信号必须通过驱动模块放大为大功率信号（数百毫安到数安培），Arduino 引脚只是控制驱动模块的开关。这也解释了为什么 Servo 库使用 `write(angle)` 设置角度，而直流电机使用 `analogWrite(pin, speed)` 设置速度——前者是位置控制，后者是功率控制。理解这一区别对于选择合适的电机类型和设计控制算法至关重要。

### Q5: 在遥控小车项目中，如果发现电机转速不一致导致小车跑偏，有哪些可能的原因和解决方案？

**答**：电机转速不一致是机器人项目中最常见的问题之一，原因可能涉及硬件、软件和机械多个层面。首先是电机本身的个体差异：即使是同一型号的电机，由于制造公差，空载转速可能相差 5-10%。廉价电机的差异更大，磁铁强度、线圈匝数、轴承摩擦都可能不同。其次是供电问题：如果使用面包板或杜邦线连接，接触电阻可能导致两个电机的实际电压不同；电池电量不足时，内阻增大会加剧这一现象。机械因素也很关键：轮子直径差异、轴承松紧不一、地面摩擦力不均都会影响实际速度。

软件层面的解决方案包括速度校准和开环补偿。最简单的方法是测量两个电机在相同 PWM 值下的实际转速（可以用编码器或计时测距），然后为较快的电机降低 PWM 占空比，或为较慢的电机提高占空比。例如，如果左电机在 PWM=200 时转速比右电机快 10%，可以将左电机的 PWM 设为 180，或将右电机设为 220。更优雅的做法是在代码中定义校准系数：`leftSpeed = baseSpeed * 0.9; rightSpeed = baseSpeed * 1.0;`，这样调整一个参数就能影响所有运动。

硬件层面的改进包括使用编码器实现闭环控制。通过实时监测每个电机的转速，使用 PID 算法动态调整 PWM 输出，使实际转速始终跟随目标值。这种方案能自动适应负载变化、电池电压下降等因素，是专业机器人的标准做法。此外，改善供电质量也很重要：使用粗短的电源线、在驱动模块附近并联大电容（如 100μF-1000μF）稳定电压、确保所有地线可靠连接。机械方面，选择配对的电机和轮子、定期清洁轴承、确保车架刚性都能减少偏差。对于要求不高的入门项目，软件校准通常已经足够；而竞赛级机器人则需要编码器反馈和精密机械加工的配合。
