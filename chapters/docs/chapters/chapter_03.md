## 3.2 控制器：机器人的大脑

### 单板计算机 vs 微控制器

| 特性 | 单板计算机 | 微控制器 |
|------|-----------|---------|
| 操作系统 | Linux（Ubuntu） | 裸机/RTOS |
| 性能 | 高（多核 CPU） | 低（单核） |
| 内存 | GB 级 | KB-MB 级 |
| 价格 | 较高（$35-$100+） | 低（$5-$20） |
| 功耗 | 高（5-15W） | 低（<1W） |
| 适用场景 | 高层决策、视觉处理 | 实时控制、传感器读取 |

### 推荐的单板计算机

**Raspberry Pi 4（推荐初学者）**
- CPU：4核 1.5GHz
- 内存：4GB/8GB
- 价格：$55-$75
- 优点：生态完善、资料丰富、ROS 2 支持好
- 缺点：性能有限，不适合深度学习

**Jetson Nano（推荐进阶）**
- GPU：128核 Maxwell
- 内存：4GB
- 价格：$99
- 优点：GPU 加速，适合视觉和深度学习
- 缺点：功耗较高

**Jetson Orin Nano（高性能）**
- GPU：1024核 Ampere
- 内存：8GB
- 价格：$499
- 优点：强大的 AI 性能
- 缺点：价格高

### 推荐的微控制器

**ESP32（强烈推荐）**
- CPU：双核 240MHz
- 内存：520KB SRAM
- 价格：$5-$10
- 优点：Wi-Fi/蓝牙、性能强、便宜
- 用途：电机控制、传感器读取

**Arduino Mega 2560**
- CPU：16MHz
- 内存：8KB SRAM
- 价格：$15-$40
- 优点：简单易用、资料多
- 缺点：性能弱

**STM32F4**
- CPU：168MHz
- 内存：192KB SRAM
- 价格：$10-$20
- 优点：性能强、实时性好
- 用途：高性能实时控制

### 双控制器架构（推荐）

对于大多数机器人，推荐使用**双控制器架构**：

```
Raspberry Pi（高层）
    │
    │ 串口/USB
    │
ESP32（底层）
    │
    ├─ 电机驱动
    ├─ 编码器读取
    └─ 传感器采集
```

**分工**：
- **Raspberry Pi**：运行 ROS 2、决策、路径规划、视觉处理
- **ESP32**：实时电机控制、传感器读取、PID 控制

**优势**：
- 高层和底层解耦
- 实时性有保障
- 开发调试方便

## 3.3 电机：机器人的肌肉

### 电机类型对比

| 类型 | 特点 | 适用场景 | 价格 |
|------|------|---------|------|
| 直流减速电机 | 简单、便宜、需要编码器 | 移动机器人轮子 | $10-$30 |
| 步进电机 | 精确定位、无需编码器 | 3D 打印机、CNC | $10-$50 |
| 舵机 | 角度控制、集成驱动 | 机械臂关节、云台 | $5-$100 |
| 无刷电机 | 高效、强劲、需要 ESC | 无人机、高速移动 | $20-$200 |

### 直流减速电机（推荐移动机器人）

**关键参数**：
- **额定电压**：6V、12V、24V
- **转速**：100-300 RPM（带减速器）
- **扭矩**：1-10 kg·cm
- **减速比**：1:30 到 1:100

**推荐型号**：
- **JGA25-370**：12V、200RPM、便宜（$10）
- **JGB37-520**：12V、100RPM、扭矩大（$15）

**选择建议**：
- 小型机器人（<5kg）：12V、200RPM
- 中型机器人（5-20kg）：12V、100RPM、高扭矩
- 大型机器人（>20kg）：24V、低转速、高扭矩

### 编码器

编码器用于测量电机转速和位置，是闭环控制的关键。

**类型**：
- **增量式编码器**：输出脉冲，需要计数（常用）
- **绝对式编码器**：直接输出位置（贵）

**参数**：
- **分辨率**：每转脉冲数（PPR）
- 常见：11 PPR、500 PPR、1000 PPR

**推荐**：
- 带霍尔编码器的减速电机（11 PPR）：便宜、够用
- 光电编码器（500 PPR）：精度高

### 电机驱动器

电机驱动器将控制信号转换为电机所需的大电流。

**常用芯片**：
- **L298N**：2A、便宜（$3）、效率低（70%）
- **TB6612FNG**：1.2A、效率高（95%）、推荐小型机器人
- **BTS7960**：43A、大功率、适合大型机器人

**H 桥原理**：

```
        VCC
         │
    ┌────┼────┐
    │    │    │
   S1   电机  S2
    │    │    │
   S3   │    S4
    │    │    │
    └────┼────┘
        GND

前进：S1、S4 导通
后退：S2、S3 导通
刹车：S1、S2 导通（或 S3、S4）
```

**PWM 调速**：
- 通过改变 PWM 占空比控制电机速度
- 频率：1kHz - 20kHz（推荐 10kHz）

## 3.4 电源系统

电源是机器人的生命线，设计不当会导致各种问题。

### 电池选择

**锂聚合物电池（LiPo）**（推荐）
- **电压**：单节 3.7V，常用 2S（7.4V）、3S（11.1V）
- **容量**：2000mAh - 10000mAh
- **放电倍率**：20C - 50C
- **优点**：能量密度高、放电能力强
- **缺点**：需要小心充放电，过放会损坏

**18650 锂电池组**
- **电压**：单节 3.7V
- **容量**：2500-3500mAh/节
- **优点**：安全、便宜
- **缺点**：重量大

**选择建议**：
- 小型机器人（<2kg）：2S 2200mAh LiPo
- 中型机器人（2-10kg）：3S 5000mAh LiPo
- 大型机器人（>10kg）：4S 10000mAh LiPo 或 18650 组

### 电源管理

**多电压系统**：

```
LiPo 电池（11.1V 3S）
    │
    ├─ 电机驱动（11.1V）
    │
    ├─ 5V 稳压器 ──> Raspberry Pi（5V 3A）
    │
    └─ 5V 稳压器 ──> ESP32、传感器（5V 2A）
```

**推荐稳压器**：
- **LM2596**：降压模块、3A、便宜（$2）
- **XL4015**：降压模块、5A、效率高（$3）
- **UBEC**：专为 RC 设计、5V/6V 可调、5A（$5）

**重要提示**：
- Raspberry Pi 需要 5V 3A 稳定电源
- 不要让电机和计算机共用电源（会产生干扰）
- 使用电容滤波（1000μF）

### 电池监控

**电压监控**：
- 使用分压电路监测电池电压
- 低于安全电压时报警（LiPo 单节 3.3V）

**电流监控**：
- 使用电流传感器（如 INA219）
- 监测功耗，估算续航时间

- 安装多个（前、后、左、右）

- 检测低矮障碍物

### 编码器

前面已经介绍，这里补充：

**安装位置**：
- 电机轴（测量电机转速）
- 轮子轴（测量轮子转速，更准确）

**里程计**：
- 通过编码器计算机器人移动距离
- 公式：`distance = (pulses / PPR) * wheel_circumference`

## 问答环节

**Q1：Raspberry Pi 能直接控制电机吗？**

A：不推荐。Raspberry Pi 的 GPIO 输出电流很小（16mA），无法直接驱动电机。应该使用电机驱动器（如 L298N）。

**Q2：为什么需要编码器？**

A：编码器提供反馈，让你知道电机实际转了多少。没有编码器，你只能"盲目"地给电机发送命令，无法精确控制。

**Q3：LiPo 电池安全吗？**

A：正确使用是安全的。注意：
- 不要过充（>4.2V/节）
- 不要过放（<3.0V/节）
- 使用专用充电器
- 存储时保持 3.8V/节
- 损坏或鼓包立即停用

**Q4：激光雷达是必需的吗？**

A：对于导航机器人，激光雷达是最可靠的传感器。如果预算有限，可以先用超声波 + 摄像头，但效果会差很多。

**Q5：如何选择电机功率？**

A：粗略估算：
- 机器人总重量（kg）× 重力加速度（9.8）× 轮子半径（m）= 所需扭矩（N·m）
- 留 2-3 倍余量
- 考虑加速度和爬坡需求

## 3.6 硬件技术发展史：从工业巨兽到创客革命

### 执行器的演进：从液压到智能电机

#### 第一代：液压与气动时代（1960s-1980s）

早期工业机器人几乎全部采用液压驱动，因为当时电机技术无法提供足够的功率密度。

**Unimate（1961）** - 世界第一台工业机器人
- 制造商：Unimation（由George Devol和Joseph Engelberger创立）
- 驱动方式：液压
- 重量：1.8吨
- 负载：12kg
- 应用：通用汽车焊接生产线

**为什么用液压？**
- 功率密度高：液压缸能产生巨大的力
- 技术成熟：来自航空航天和重工业
- 缺点：漏油、维护复杂、精度低

**Joseph Engelberger（1925-2015）** 被誉为"工业机器人之父"，他不仅发明了Unimate，还创立了第一家机器人公司，推动了机器人的商业化。

#### 第二代：电机革命（1980s-2000s）

**永磁同步电机（PMSM）** 的成熟改变了机器人驱动方式：
- 更高的效率（>90%）
- 更好的控制精度
- 更小的体积和重量

**关键突破**：
- **稀土永磁材料**（钕铁硼，1980s）：磁场强度提升10倍
- **矢量控制算法**（Field-Oriented Control）：让交流电机像直流电机一样易控制
- **高性能编码器**：分辨率从1000线提升到100万线

**FANUC（发那科）** 在1980年代率先将全电动机器人推向市场，成为工业机器人的领导者。

#### 第三代：智能执行器时代（2010s-至今）

**准直驱电机（Quasi-Direct Drive）** 的出现是近年来最重要的突破：

**MIT Cheetah（2013-至今）**
- 开发者：MIT Biomimetic Robotics Lab（Sangbae Kim教授）
- 创新：高扭矩密度电机 + 低减速比（6:1）
- 结果：能跑、能跳、能后空翻的四足机器人

**为什么准直驱重要？**
传统机器人用高减速比（50:1甚至100:1）来提升扭矩，但这会：
- 降低响应速度
- 增加摩擦和间隙
- 无法感知外力（力控制困难）

准直驱通过提升电机本身的扭矩密度，用更低的减速比实现：
- 高带宽力控制
- 快速响应
- 更好的能量效率

**波士顿动力（Boston Dynamics）** 的Atlas和Spot机器人也采用了类似技术，这是它们能做出惊人动作的关键。

**中国的贡献**：
- **宇树科技（Unitree）**：推出了低成本的准直驱四足机器人（Go1仅$2700）
- **大疆（DJI）**：RoboMaster电机成为教育机器人的标准配置

### 传感器的革命：从昂贵到普及

#### 激光雷达的平民化

**早期激光雷达（1990s-2000s）**：
- **SICK LMS**：工业标准，但价格高达$5000-$10000
- 应用：仅限于研究机构和高端工业应用

**转折点：Hokuyo URG（2005）**
- 价格：$1000
- 性能：4米测距、240°视角
- 影响：让大学实验室也能用上激光雷达

**创客时代：RPLIDAR（2014）**
- 制造商：思岚科技（Slamtec，中国）
- 价格：$99（A1型号）
- 性能：12米测距、360°扫描
- 影响：激光雷达进入创客圈，催生了大量DIY机器人项目

**固态激光雷达（2020s）**：
- 无机械旋转部件
- 更小、更便宜、更可靠
- 代表：Livox（大疆子公司）、Ouster

#### 深度相机的崛起

**微软Kinect（2010）** 是深度视觉的分水岭：
- 价格：$150（游戏外设）
- 技术：结构光
- 影响：让3D视觉从$10000降到$150，催生了大量研究

**后Kinect时代**：
- **Intel RealSense**（2014）：更小、更精确
- **Orbbec Astra**（2016）：中国品牌，性价比高
- **iPhone LiDAR**（2020）：消费级设备集成ToF传感器

**关键人物**：
- **Alex Kipman**（微软）：Kinect的首席发明人
- **Dieter Fox**（华盛顿大学 → NVIDIA）：将Kinect用于机器人SLAM的先驱

### 计算平台的演进

#### 嵌入式计算的三次革命

**第一次：Arduino（2005）**
- 创始人：Massimo Banzi等（意大利）
- 创新：开源硬件 + 简化的IDE
- 影响：让非专业人士也能做嵌入式开发
- 价格：$25

**第二次：Raspberry Pi（2012）**
- 创始人：Eben Upton（英国）
- 创新：$35的Linux计算机
- 影响：让机器人能运行复杂算法（ROS、OpenCV）
- 销量：超过4000万台

**第三次：边缘AI芯片（2015-至今）**
- **NVIDIA Jetson**（2015）：GPU加速的AI计算
- **Google Coral**（2019）：TPU边缘计算
- **地平线（Horizon Robotics）**（2020）：中国自研AI芯片

**性能对比**：
```
Arduino Uno (2010):    16 MHz,  2KB RAM
Raspberry Pi 4 (2019): 1.5 GHz, 8GB RAM (750倍提升)
Jetson Orin (2022):    2.2 GHz, 32GB RAM + 275 TOPS AI算力
```

### 电池技术的突破

#### 从镍镉到锂聚合物

**镍镉电池（NiCd, 1950s-1990s）**
- 优点：便宜、耐用
- 缺点：记忆效应、重金属污染
- 能量密度：40-60 Wh/kg

**镍氢电池（NiMH, 1990s-2010s）**
- 优点：无记忆效应、环保
- 能量密度：60-120 Wh/kg
- 应用：早期混合动力汽车、机器人

**锂聚合物电池（LiPo, 2000s-至今）**
- 能量密度：150-250 Wh/kg（是NiCd的4倍）
- 放电倍率：20C-50C（能提供瞬时大电流）
- 应用：无人机、竞速机器人

**关键突破**：
- **John Goodenough**（2019年诺贝尔化学奖）：发明了锂离子电池的钴酸锂正极
- **吉野彰**（2019年诺贝尔化学奖）：开发了第一个商用锂离子电池

**中国的崛起**：
- **宁德时代（CATL）**：全球最大的动力电池制造商
- **比亚迪（BYD）**：刀片电池技术

### 开源硬件运动

#### 从闭源到开放

**传统模式（1960s-2000s）**：
- 硬件设计是商业机密
- 维修需要原厂授权
- 创新被大公司垄断

**开源硬件运动（2005-至今）**：

**Arduino（2005）** - 开源硬件的先驱
- 开放电路图和PCB设计
- 任何人都可以制造兼容板
- 催生了数千个衍生项目

**影响**：
- **降低门槛**：从需要电子工程学位到高中生都能做
- **加速创新**：全球开发者共享设计和代码
- **降低成本**：竞争让价格从$100降到$3（兼容板）

**重要项目**：
- **OpenROV**（2012）：开源水下机器人
- **PX4**（2013）：开源飞控系统（大疆早期使用）
- **ODrive**（2016）：开源电机驱动器

**中国的开源硬件**：
- **立创EDA（LCEDA）**：免费的PCB设计工具
- **嘉立创（JLCPCB）**：$2就能打样PCB
- **矽递科技（Seeed Studio）**：开源硬件生态系统

### 标准化的力量

#### 接口标准的演进

**机械接口**：
- **DIN标准**（德国）：工业机器人法兰标准
- **ISO 9409**：机器人末端执行器接口国际标准

**通信协议**：
- **CAN总线**（1980s）：汽车和工业机器人的标准
- **EtherCAT**（2003）：实时以太网，用于高性能机器人
- **ROS标准消息**（2010s）：软件层面的标准化

**为什么标准化重要？**
- 不同厂商的组件可以互换
- 降低开发成本
- 加速创新（站在巨人的肩膀上）
