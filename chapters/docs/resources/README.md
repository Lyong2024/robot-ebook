# 机器人电子书 - 拓展资源索引

本目录包含每章的深度拓展资源，帮助读者深入学习机器人技术。

## 📚 资源类型说明

每章的拓展资源包括：

- **📖 权威文献**：国际标准、行业报告、白皮书
- **📄 学术论文**：经典论文、最新研究、综述文章
- **📕 经典书籍**：教材、专著、技术手册
- **🎥 视频教程**：在线课程、技术讲座、实验演示
- **📜 历史文献**：专利文档、历史回顾、人物传记
- **🛠️ 实用工具**：开源库、在线工具、仿真平台
- **📊 数据集**：公开数据集、基准测试、模型库
- **🔗 社区资源**：论坛、博客、开源项目

## 🎯 使用建议

### 初学者
1. 先阅读主章节内容
2. 查看"经典书籍"和"视频教程"部分
3. 使用"实用工具"进行实践
4. 参与"社区资源"讨论

### 进阶学习者
1. 深入阅读"学术论文"
2. 研究"历史文献"了解技术演进
3. 使用"数据集"进行实验
4. 贡献"开源项目"

### 研究人员
1. 追踪"权威文献"和最新标准
2. 阅读顶会论文（ICRA、IROS、RSS）
3. 使用"基准测试"评估算法
4. 发表研究成果
